# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 6.x.x   | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

We value the insights of the security community and encourage responsible disclosure. If you discover a vulnerability, please do not use public GitHub issues, discussions, or pull requests to report it. 

### How to Disclose
Instead of a public post, please report vulnerabilities through the following channels:

* **GitHub Private Vulnerability Reporting:** Navigate to the "Security" tab of this repository, select "Vulnerability reporting" from the sidebar, and click "Report a vulnerability".

### What to Include
To help us understand and fix the issue quickly, please include:
1. **Description:** The type of issue (e.g., SQL injection, Remote Code Execution).
2. **Location:** The affected file paths, branches, or direct URLs.
3. **Steps to Reproduce:** A clear description or proof-of-concept (PoC) script.
4. **Impact:** How an attacker could exploit this vulnerability.

Thank you for helping keep our software secure!
